Privacy Policy for NEXPAD

Effective Date: October 2026 • Application: NEXPAD Virtual Controller

Summary: NEXPAD collects zero personal data, includes zero third-party trackers or ads, and transmits controller input data exclusively across your local network or direct USB cable to your personal computer.

NEXPAD ("we", "our", or "the application") is an open-source virtual gamepad and HUD controller developed by Sanket Parmar. We respect your privacy and are committed to protecting it through transparent, privacy-first software architecture.

1. Zero Personal Data Collection

NEXPAD operates entirely as a local, peer-to-peer virtual input client:

  • No Personal Information: We do not collect, request, store, or transmit your name, email address, phone number, location, or device identifiers.
  • No Telemetry or Tracking: There are no third-party analytics SDKs, advertising networks, or telemetry trackers embedded in the application.
  • No Cloud Servers: NEXPAD does not communicate with external cloud servers. All input signals stream strictly between your Android device and your designated PC host.

2. Permissions and Purpose

NEXPAD requests only the minimal set of hardware permissions necessary to function as a physical gamepad replacement:

Permission Purpose Data Handling
Internet & Wi-Fi
INTERNET
ACCESS_WIFI_STATE		 Transmits ultra-low-latency UDP gamepad controller packets to NEXPAD Desktop on your local network. Data stays strictly on your local private network. Never routed over the public internet.
Bluetooth
BLUETOOTH_CONNECT
BLUETOOTH_SCAN		 Enables optional wireless Bluetooth RFCOMM serial connection between phone and PC. Local device-to-PC pairing only. Location flags are disabled via neverForLocation.
USB Accessory
android.hardware.usb.accessory		 Supports zero-driver wired connection using the Android Open Accessory (AOA) protocol. Direct hardware wire communication with host PC.
Sensors
Gyroscope & Accelerometer		 Captures device orientation for 6-axis motion aiming and virtual steering wheel emulation. Streams real-time motion coordinates directly to host PC. Sensor data is never saved, logged, or uploaded.
Vibrate
VIBRATE		 Provides tactile haptic feedback for button presses and game force-feedback rumble. Hardware motor control only.

3. Local Storage and Preferences

Custom controller HUD layouts, analog sensitivities, and connection IP addresses are stored purely on your local device storage using Android Jetpack DataStore / SharedPreferences. This configuration data never leaves your device unless you manually choose to export a layout file.

4. Children’s Privacy

NEXPAD does not knowingly collect, store, or transmit personal information from children under the age of 13. The application contains no ads, in-app purchases, or social networking features.

5. Open Source Transparency

NEXPAD is open-source software licensed under the Apache License 2.0. The complete source code is publicly accessible on GitHub for verification and community review.
